# Smart Dental Clinic — مراجعة ملف العيادة v13

الأساس: **Clinic Dashboard Merged v12**. هذا التحديث لا يغيّر الشكل الأصلي ولا ينشئ صفحة جديدة أو جدول SQL.

## ما تمت مراجعته

- `/clinic/profile`: بيانات العيادة والاتصال، العنوان والإحداثيات والخريطة، الدوام الأسبوعي وخيار 24 ساعة، الاستثناءات، سجل الملفات ورفع الشعار، حالة الحجز الإلكتروني، ملخص العيادة.
- جميع نماذج الحفظ في هذه الصفحة تستخدم نفس المسارات الحالية، مع حماية CSRF وفحص مدير العيادة في Backend.
- تأكد فحص الكود من أن البيانات مقروءة من PostgreSQL ولا تُعرض سجلات عيادة تجريبية في صفحة حقيقية.

## الإصلاحات الجديدة

1. إذا كان تعديل الدوام الأسبوعي أو الاستثناءات سيجعل موعدًا مؤكدًا أو معلقًا يقع خارج أوقات عمل العيادة، يُرفض التعديل وتُلغى المعاملة (ROLLBACK) مع رسالة داخل صفحة الملف الشخصي.
2. لا يُقبل تاريخ استثناء غير موجود في التقويم (مثل 31 فبراير).
3. إيقاف الحجز الإلكتروني مع وجود حجوزات AI معلقة/مؤكدة يُرفض برسالة واضحة وفق قيد قاعدة البيانات الحالية، بدل ظهور خطأ خادم عام.
4. إذا كشف قيد PostgreSQL تعارضًا في آخر لحظة، تظهر رسالة آمنة داخل نفس صفحة الإعدادات بدل صفحة خطأ جديدة. لا تُعرض تفاصيل SQL للمتصفح.

## ملفات الـ Patch

- `src/clinic-settings-service.js`
- `src/clinic-settings-router.js`
- `tests/clinic-settings.test.js`

## التركيب

1. خذ نسخة احتياطية من ملفات المشروع، وأوقف السيرفر.
2. فك الضغط وانسخ مجلدات `src` و`tests` داخل **مشروع v12 الحالي**، بنفس المسارات، مع الاستبدال. لا تنسخ مجلد الـ Patch الخارجي نفسه.
3. **لا تغيّر `.env`، ولا تشغّل ملفات SQL أو Seed.**
4. نفّذ:

```cmd
npm test
npm start
```

## التحقق

- نجاح `npm test` وفحص القوالب الـ110 والمسارات محليًا.
- 132 اختبارًا برمجيًا ناجحًا عبر تشغيل جميع ملفات `*.test.js` دفعة واحدة.
- **لم يُختبر اتصال قاعدة PostgreSQL الخاصة بالمستخدم أو المتصفح في بيئته**؛ لا تعتمد وظيفة دون الاختبار العملي.

## تجربة عملية مقترحة

1. من `/clinic/profile` غيّر الهاتف واحفظ، ثم حدّث الصفحة؛ يجب أن يبقى التغيير.
2. أضف استثناء إغلاق بتاريخ يوجد فيه موعد مؤكد؛ يجب **رفض الحفظ** مع الإبقاء على الاستثناءات القديمة.
3. أضف استثناء إغلاق بتاريخ مستقبلي لا يحتوي مواعيد؛ يجب أن يُحفظ ويظهر بعد تحديث الصفحة.
4. تأكد أن الدوام 24 ساعة والشعار والخريطة وقائمة المستندات تعمل بتصميمها السابق.

## حدود النسخة الحالية

- لا تُعدّل هذه الحزمة منطق حجز المواعيد أو الجدول الطبي للطبيب.
- قيد قاعدة البيانات الحالي يمنع إغلاق الحجز الإلكتروني أثناء وجود مواعيد AI معلقة/مؤكدة، وبالتالي سيظهر تنبيه واضح بدل تغيير تلك السياسة خفيةً.
- تدوير مفتاح MFA المسرب سابقًا مسار أمني منفصل ويحتاج خطة تحافظ على إمكانية الدخول.

**الصفحة التالية في خطة تدقيق دور العيادة:** `/clinic/account-settings`.
