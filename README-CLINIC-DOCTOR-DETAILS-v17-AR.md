# Smart Dental Clinic — Clinic Doctor Details v17

التحديث مبني **فقط على النسخة v16** (`Smart-Dental-Clinic-Doctor-Without-Clinic-UI-Merged-v16.zip`).

## ما الذي تغير؟
- إبقاء صفحة `views/clinic/doctor-details.ejs` الأصلية وتصميمها كما هو، وتصحيح شاراتها لتعرض تخصص الطبيب وحالة عضويته بحسب البيانات الفعلية بدل «متاحة اليوم» الثابتة.
- زر «إدارة العضوية» ينقلك إلى صفحة `/clinic/doctors` الموجودة بدل زر تعطيل وهمي.
- لا يمكن حذف فترة دوام إذا كانت تحتوي على حجوزات قائمة لا تغطيها فترة دوام أخرى نشطة.
- لا يمكن تسجيل غياب / إجازة فوق حجوزات معلقة أو مؤكدة أو زيارة جارية تخص الطبيب في نفس العيادة.
- لا يمكن تسجيل غياب يتداخل مع غياب سابق في العيادة نفسها.
- تعديل فترة الدوام يفحص المواعيد الحالية والمستقبلية، وليس المواعيد التاريخية فقط.
- أي خطأ أثناء حفظ تعديل الدوام أو الغياب يظهر داخل صفحة تفاصيل الطبيب الأصلية، مع الحفاظ على بياناته.
- جميع العمليات ما زالت تتحقق من مدير العيادة وCSRF، وتستخدم معاملات PostgreSQL وAudit Log الموجودين أصلًا.

## الملفات المعدلة/المضافة في Patch
- `src/appointments/schedule.js`
- `src/appointments/router.js`
- `views/clinic/doctor-details.ejs`
- `tests/clinic-doctor-details.test.js` (جديد)
- `tests/directory-live.test.js`
- `tests/verify-structure.js`
- `package.json` لإضافة الاختبار الجديد إلى أمر `npm test`

## التركيب
1. أوقف السيرفر الحالي وخذ نسخة احتياطية من المشروع.
2. فك ZIP الخاص بالـPatch وانسخ محتوياته مباشرة إلى مشروع v16 (المجلد الذي يحتوي `package.json`). وافق على استبدال الملفات المطابقة.
3. **لا تستبدل `.env`، ولا تشغّل Seed أو SQL جديدًا.**
4. من CMD داخل المشروع شغّل `npm test` ثم `npm start`.
5. افتح `/clinic/doctors` واختر طبيبًا نشطًا، ثم افتح ملفه من زر «الملف والدوام».

## اختبارات المتصفح المقترحة
1. راجع أن تخصص الطبيب وحالة العضوية تظهر بشكل منطقي، وأن الخدمات المخصصة والفترات والغيابات تُقرأ من PostgreSQL.
2. أنشئ موعدًا مؤكدًا مستقبلًا ضمن فترة دوام محددة؛ حاول حذف هذه الفترة إن لم توجد فترة بديلة تغطي الحجز. يجب رفض الحذف داخل نفس الصفحة وبقاء الحجز.
3. جرّب غيابًا يغطي تاريخ الموعد نفسه؛ يجب رفضه وبقاء الموعد.
4. جرّب غيابًا في فترة فارغة؛ يجب حفظه واسترجاعه بعد تحديث الصفحة.
5. جرّب غيابًا ثانيًا يتداخل مع الغياب الأول؛ يجب رفضه.
6. تحقق أن زر «إدارة العضوية» يفتح صفحة أطباء العيادة الأصلية.

## نطاق الفحص
فُحصت القوالب الـ110 وروابطها، ونجحت 151 تجربة آلية باستعمال `node --test tests/*.test.js`، وتحققت سكربتات البنية والتوجيه والواجهات الموحدة. **لم يتم اختبار اتصال PostgreSQL الحقيقي أو المتصفح في جهاز المستخدم**، وتعذر تنفيذ `npm install` داخل بيئة التجهيز دون الوصول إلى حزم npm. لا تدّعي الحزمة إكمال كل صفحات دور العيادة؛ هذا تحديث صفحة «تفاصيل الطبيب» فقط.
