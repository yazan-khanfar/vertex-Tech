# Smart Dental Clinic — Doctor Schedule Edit v9

## هدف التحديث
إضافة زر «تعديل» بجانب زر «حذف» في جدول دوام الطبيب الموجود داخل `/clinic/doctor-details`، باستخدام **نافذة إضافة فترة الدوام نفسها**، بلا تغيير في التصميم أو إنشاء صفحة جديدة.

## ما الذي أصبح ممكنًا؟
- تعديل اليوم ووقت البداية والنهاية والحالة (نشطة/غير نشطة).
- اختيار نهاية اليوم `24:00` عبر مربع «حتى نهاية اليوم».
- تحديث صف الدوام الحالي في جدول `DOCTOR_WORKING_HOURS` مباشرة بدل حذف الصف وإنشاء صف بديل.
- التحقق من عضوية الطبيب وصلاحية مدير العيادة، ومنع التداخل مع دوامه في كل العيادات.
- منع التعديل الذي يترك حجزًا مؤكدًا أو بانتظار الموافقة خارج أي فترة دوام فعالة.
- تسجيل التعديل في `AUDIT_LOG`.

## الدمج (Patch)
1. خذ نسخة احتياطية من مجلد مشروعك ثم أوقف السيرفر بـ Ctrl+C.
2. فك ضغط ملف Patch v9.
3. **انسخ الملفات والمجلدات التي داخل ZIP** إلى نفس مجلد مشروعك الذي يحتوي `package.json`؛ اختر استبدال الملفات المطابقة.
4. **لا تستبدل `.env`**، ولا تشغّل أي SQL أو Seed جديدًا.
5. نفّذ داخل المشروع:
   ```cmd
   npm test
   npm start
   ```
6. افتح حساب مدير العيادة → الأطباء → تفاصيل الطبيب → «الدوام وإعدادات المواعيد». بجانب كل فترة زر «تعديل». غيّر وقت النهاية مثلًا ثم احفظ وحدّث الصفحة.
7. للتحقق من القواعد، جرّب تغيير الفترة لتتداخل مع فترة أخرى أو تُخرج حجزًا مؤكدًا منها؛ يجب أن يرفض النظام مع رسالة واضحة.

- نظام الحجز يعرض فقط تقاطع دوام الطبيب مع دوام العيادة والاستثناءات.
