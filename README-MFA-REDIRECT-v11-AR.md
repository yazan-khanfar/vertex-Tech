# Smart Dental Clinic — إصلاح تفعيل وتعطيل MFA داخل الصفحات الأصلية (v11)

## سبب المشكلة

في نسخة v10 كانت عمليات `/auth/security/start`, `/confirm`, `/disable` ترسم صفحة الملف الشخصي مباشرةً في **عنوان عملية POST**. معظم ملفات CSS/JS تستخدم مسارات نسبية تختلف حسب العنوان، ولهذا ظهرت صفحة بيضاء غير منسقة، كما في الصورة التي أرسلتها.

## الإصلاح

- تُعيد العمليات إلى صفحة الحساب الأصلية باستخدام HTTP 303 (Post/Redirect/Get)، مثل `/patient/profile#sdc-mfa`, `/doctor/profile#sdc-mfa`, `/clinic/account-settings#sdc-mfa`, `/staff/profile#sdc-mfa`, `/admin/settings#sdc-mfa`.
- تظهر رسائل الأخطاء والنجاح على الصفحة الأصلية بعد التحويل، دون إضافتها إلى URL.
- تبقى بيانات إعداد تطبيق المصادقة مؤقتًا أثناء الإعداد فقط.
- تُعرض رموز الاسترداد مرة واحدة بعد التفعيل؛ تستخدم ذاكرة عابرة لمدة لا تزيد عن دقيقتين ثم تُمحى بعد أول عرض. لا تُوضع الرموز في الرابط أو ملفات السجلات أو قاعدة البيانات كنص عادي.
- يُفتح تبويب «الأمان» تلقائيًا على صفحة إعدادات Super Admin عند العودة من عملية MFA.
- **لا توجد صفحات إضافية** ولا أي تغيير في CSS أو PostgreSQL أو مفاتيح MFA.

## تركيب الـPatch

1. أوقف الخادم بـ `Ctrl+C`، وخذ نسخة احتياطية من المشروع.
2. فك ضغط Patch v11 ثم انسخ الملفات والمجلدات الموجودة بداخله مباشرة إلى **جذر مشروع v10** (حيث `package.json`)، ووافق على استبدال الملفات المطابقة.
3. لا تنسخ أو تستبدل `.env`، ولا تغيّر `MFA_ENCRYPTION_KEY`، ولا تعيد إنشاء قاعدة البيانات أو تشغيل Seed.
4. شغّل من المجلد الذي فيه `package.json`:

   ```cmd
   npm test
   npm start
   ```

5. جرّب من حساب مريض ثم مشرف، واضغط تفعيل أو تعطيل المصادقة. يجب الرجوع إلى **نفس صفحة الحساب الأصلية** مع تصميمها الكامل ورسالة واضحة. عند التفعيل احفظ رموز الاسترداد فور عرضها.

**ملاحظة:** في حال كنت تستخدم النسخة الكاملة v11 بدل Patch، انسخ `.env` القديم إلى جذر المشروع الجديد أولًا. لا تحتاج إلى تنفيذ أي SQL.

## التحقق

- نجحت الاختبارات المستقلة لمسارات MFA والرسائل العابرة وعزل الجلسات (12/12 لاختبارات MFA المرتبطة).
- نجح فحص القوالب الـ110 وروابطها والـAssets.
- لا يمكن إجراء اختبار PostgreSQL ومتصفح Windows لديك من بيئة التجهيز، لذا نحتاج اختبارك الفعلي.
