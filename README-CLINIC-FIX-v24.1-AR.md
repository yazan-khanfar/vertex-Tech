# Smart Dental Clinic — تحديث إصلاحات v24.1

**الأساس:** `Smart-Dental-Clinic-Clinic-Batch-4-Merged-v24.zip`.
**النطاق:** حل مشكلتين أبلغ عنهما المستخدم أثناء تجربة v24، من دون تعديل قاعدة البيانات أو إعادة تصميم الصفحات.

## 1) إصلاح فتح صفحة الوظائف

- **سبب مؤكد في كود v24:** استعلام `src/clinic-remaining-service.js` كان يطلب `sdc."SPECIALTY"."Specialty_Name"` بينما مخطط قاعدة البيانات المرفق يحتوي `Name_AR` و`Name_EN` فقط.
- أُصلح استعلام جلب الوظائف ليستخدم `s."Name_AR" AS "Specialty_Name"`؛ وأُصلح جلب خيارات التخصص إلى `"Name_AR" AS "Specialty_Name"`، مع الاقتصار على التخصصات النشطة.
- لم يتغير اسم أي عمود في قاعدة PostgreSQL أو قالب الوظائف أو سير عمل إنشاء الإعلانات.
- **حالة الاعتماد:** اجتاز اختبار التوافق مع SQL واختبارات وحدة وهمية. لم يُجرّب تسجيل الدخول وفتح الصفحة على قاعدة المستخدم المحلية؛ يجب التأكد عمليًا أن الخطأ اختفى وإتمام سيناريو إضافة وظيفة وتعديلها.

## 2) إصلاح قائمة إشعارات العيادة

- أُدرجت نسخة الهيدر الخاصة بالصفحة الرئيسية في فئة `notification-menu-safe` نفسها المستخدمة في نسختي الهيدر الأخريين.
- أضيفت قواعد CSS **محدودة بقائمة الإشعارات**؛ على الشاشات الصغيرة تصبح القائمة داخل حدود العرض، مع التفاف للنص وتمرير رأسي بدلاً من الخروج خارج الشاشة.
- لم يُعد تصميم البطاقات أو الصفحة ولم تُغيّر نصوص الإشعارات أو البيانات أو عمليات القراءة والحذف.

## 3) نتائج الفحوص

- 30/30 اختبار وحدة ناجحًا لوحدات v20/v21/v24، منها اختباران جديدان لمنع تكرار الخطأ.
- تصيير ثابت ناجح لـ 110 قوالب EJS وفحص 2946 رابطًا داخليًا.
- فحوص المسارات والهيدر والفوتر ناجحة.
- **فحص متصفح مرئي محلي:** قائمة تجريبية تحتوي 8 إشعارات فُحصت عند عروض 375 و525 و768 و1024 بكسل في Chromium، وجميعها داخل حدود نافذة العرض؛ النصوص والأزرار ظاهرة والقائمة قابلة للتمرير.
- فحص المتصفح استُخدمت فيه بيانات إشعارات تجريبية للمعاينة فقط، ولم تُعدّل البيانات الحقيقية.
- **لم تتوفر قاعدة PostgreSQL المحلية** في بيئة الاختبار، لذلك لا يمكن الجزم بنجاح الربط الفعلي إلى أن يُختبر على جهاز المستخدم.

## 4) حالة الاختبارات بحسب المستخدم

- **المختبرات:** تأجيل إلى حين ربط المشرف بإدارة المختبرات، ثم فحص الطرفين.
- **الوظائف:** إعادة الاختبار بعد تطبيق هذا الإصلاح.
- **المستندات:** أكد المستخدم نجاحها في v24؛ لم تُغيّر في هذه الدفعة.
- **الإشعارات:** إعادة اختبار التنسيق والتفاعل على الصفحة الرئيسية، ومراجعة صفحة أخرى من العيادة.
- **التقارير والإحصائيات:** تأجيل اختبارات الإيرادات والتكامل حتى اكتمال دور الطبيب.

## 5) طريقة تطبيق الـPatch

فك `Smart-Dental-Clinic-Clinic-Fixes-Patch-v24-to-v24.1.zip` **داخل مجلد مشروع v24 نفسه**، مع استبدال الملفات المتطابقة. لا تُطبقه على نسخة v23 أو أقدم. احتفظ بملف `.env` الحالي دون أي تعديل. أعد تشغيل الخادم ثم حدّث الصفحة تحديثًا قويًا (Ctrl+F5) ليحمّل المتصفح CSS الجديد.

إذا كنت غير متأكد من إصدار مشروعك، استخدم `Smart-Dental-Clinic-Clinic-Fixes-Merged-v24.1.zip` وافتحه في مجلد مستقل، مع نقل إعدادات `.env` المحلية بنفس قيمها.
