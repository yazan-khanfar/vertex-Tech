# Smart Dental Clinic — Gender Display & Registration Fix v18.2

## المشكلة
التسجيل الذاتي للمريض في النسخ السابقة كان يحفظ `Gender` بالعربية (`ذكر` / `أنثى`)، بينما صفحة تفاصيل المريض داخل العيادة كانت تعتبر أي قيمة غير `male` أنثى. لذلك ظهر جنس بعض المرضى بصورة خاطئة.

## الإصلاح
- أضفنا دالة موحّدة `src/patients/gender.js` لفهم القيم القديمة والجديدة، وعرض أي قيمة غير معروفة كـ«غير محدد» بدل تخمين الجنس.
- تفاصيل المريض في `views/clinic/patient-details.ejs` تعرض القيمة المقروءة الصحيحة من سجل المريض.
- تسجيل المريض من `views/auth/register/patient.ejs` يُرسل `male` / `female`، ويقبل الـBackend أيضًا القيم العربية القديمة، ويحوّلها لصيغة واحدة قبل حفظها.
- إنشاء المريض من العيادة يقبل القيمتين ويخزّن الصيغة الموحدة.
- اختبارات منع التراجع تغطي القيمة `ذكر` المخزّنة بالفعل في قاعدة البيانات.

## التركيب — Patch فوق v18.1
1. أوقف السيرفر (`Ctrl+C`).
2. خذ نسخة احتياطية من المشروع.
3. فك ضغط حزمة Patch v18.2، وانسخ **محتوياتها** إلى جذر المشروع الحالي بجانب `package.json` مع استبدال الملفات المتطابقة.
4. نفّذ `npm test` ثم `npm start`.
5. افتح صفحة ملف المريض القديم وحدّث (`Ctrl+F5`). الجنس المخزّن `ذكر` سيظهر «ذكر».
6. جرّب تسجيل مريض جديد ذكَر ثم افتح ملفه من العيادة بعد ارتباطه بها ضمن السيناريو الصحيح، وتحقق من قيمة Gender.

**لا SQL جديد ولا تعديل لقاعدة البيانات أو أسماء الأعمدة أو ملفات CSS أو تصميم الصفحات.** بيانات السجلات القديمة تبقى كما هي وتُقرأ بشكل صحيح. لا حاجة لتشغيل Seed أو حذف بيانات المستخدمين.
